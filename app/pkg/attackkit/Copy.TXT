ATTACKKIT NETWORK POLICY
========================

This reference file follows the MUNITOS package networking architecture.

- Package network traffic is routed through the public FreeUserProxy API.
- Packages do not manage proxy collections or proxy configuration.
- Proxy configuration is managed only by BIOS through the FreeUserProxy management API.
- User-Agent selection is provided by FreeUserProxy.
- Package code should use __FreeUserProxy.api.proxy and __FreeUserProxy.api.userAgent.
- The management API is intentionally not exposed to packages.

Supported command surface is defined by the package runtime manifest.
