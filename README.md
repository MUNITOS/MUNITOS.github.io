## What is MUNITOS?

MUNITOS is a free, browser-based virtual computing environment designed to provide a lightweight and modular experience for learning, experimentation, development, and general computing.

The project combines a virtual system environment, terminal interface, virtual file system, package system, runtime components, developer utilities, and other modular capabilities into a unified environment.

MUNITOS is designed to be accessible without requiring users to purchase a license or subscription.

---

## ✨ Why MUNITOS?

MUNITOS is built around a simple idea:

> **Powerful software should be accessible to everyone.**

The project is developed as a long-term independent project with a focus on:

- Accessibility
- Modularity
- Lightweight execution
- Developer experimentation
- Learning
- Virtualized system concepts
- Extensible packages
- A simple and familiar terminal-driven workflow

---

## 🚀 Features

### Virtual Computing Environment

MUNITOS provides a virtualized computing environment that runs through supported web technologies.

### Virtual File System

A dedicated virtual file system allows applications and packages to interact with files inside the MUNITOS environment.

### Terminal

MUNITOS provides a terminal-oriented interface for interacting with the system and installed components.

### Package System

MUNITOS includes a package architecture designed to allow additional modules and utilities to operate inside the environment.

### Runtime

The runtime provides the underlying environment required by system components and packages.

### Recovery / BIOS Components

System-level components provide initialization, recovery, environment management, and related low-level functionality.

### Developer Utilities

MUNITOS includes utilities intended for experimentation, diagnostics, development, and system interaction.

## 📦 Packages

MUNITOS supports a modular package architecture.

Official packages may include utilities for:

- System monitoring
- Diagnostics
- Networking
- Development
- File management
- Environment utilities
- Security research and authorized testing
- Other MUNITOS-compatible functionality

Official packages are distributed and maintained according to the MUNITOS package policies.

### Important

Third-party packages must not contain malicious, destructive, unauthorized, hidden, or intentionally harmful functionality.

Packages designed to:

- steal credentials,
- exfiltrate private information,
- deploy unauthorized persistence,
- compromise accounts,
- bypass access controls,
- damage systems,
- secretly collect data,
- distribute malware,
- evade MUNITOS security controls,

are prohibited.

Violations may result in immediate removal of the package, revocation of access, account suspension or termination, and other actions available to the project under applicable law.

See:

[`SECURITY.md`](SECURITY.md)

and:

[`LICENSE`](LICENSE)

## 👤 GitHub Authentication & Account Security

Some MUNITOS services may allow users to sign in using GitHub.

When GitHub authentication is used, MUNITOS may process account information made available through the authentication process and the permissions granted to the application.

Depending on the authentication configuration, this may include information such as:

- GitHub username
- GitHub account identifier
- Public profile information
- Avatar/profile image
- Email address where made available or authorized
- Authentication identifiers
- Session and login information

MUNITOS may also process technical and security information necessary to operate the service, prevent abuse, investigate violations, and protect the platform.

This information is used for legitimate operational and security purposes.

### Abuse Prevention

Where account authentication is required, MUNITOS may associate activity with the authenticated account.

If a user violates the MUNITOS rules, abuses the platform, distributes prohibited packages, attempts to bypass security controls, or engages in other prohibited activity, MUNITOS may suspend, restrict, or terminate the relevant account or service access.

Administrative tools may be used to perform these actions quickly when necessary to protect the project and its users.

MUNITOS does not require users to provide unnecessary personal information for ordinary use.

For more information, see:

[`SECURITY.md`](SECURITY.md)
